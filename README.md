# 人生養成模擬器（Life Simulator）

## 專案目標

這是一款以人生模擬為核心、結合 RPG 隨機事件的遊戲。
玩家每年選擇行動，能力值、金錢與事件會逐步累積，最後形成不同的人生故事與結局。

## 開發階段

- 第一階段：Python 終端機版基礎遊戲（已完成）
- 第二階段：JSON 存檔、讀檔、人生結算、轉生與歷代紀錄（已完成）
- 第三階段：Flask 網頁版（進行中）
- 第四階段：Firebase 雲端存檔與跨裝置同步（預計）
- 第五階段：AI NPC、動態事件與 AI API 整合（預計）

## 核心遊戲功能

1. 人生模擬系統

建立玩家角色與初始能力值。

提供工作、學習、運動、社交及休息等行動。

根據玩家選擇改變能力值、體力及存款。

透過每年的行動累積不同的人生經歷。

2. 隨機事件系統

遊戲過程中隨機觸發人生事件。

事件可能影響玩家能力值及存款。

不同事件與選擇帶來不同的遊戲結果。

3. 人生故事與結局

記錄玩家每一世的人生經歷。

根據遊戲進程產生不同人生結局。

支援重新開始人生，累積歷代人生紀錄。

4. 存檔

## 未來展望

希望將本專案發展為支援電腦與手機的網頁遊戲，讓玩家能夠隨時繼續自己的人生旅程。

未來預計加入雲端存檔、跨裝置同步及 AI 互動功能，讓 AI NPC 能夠理解玩家的自然語言，並依據遊戲情境生成對話與動態事件，使每位玩家都能創造獨特的人生故事。
